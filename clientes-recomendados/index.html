Clientes recomendados

Elija una aplicación compatible con su llave de RoCla VPN.

Con RoCla VPN, usted puede utilizar clientes de código abierto de su preferencia que sean compatibles con los protocolos de nuestro servicio, como Shadowsocks, WireGuard, X-Ray y Hysteria2.

En este artículo, le presentamos varias aplicaciones multiplataforma para gestionar sus cuentas de RoCla VPN, junto con sus enlaces de descarga, ventajas y limitaciones, para que pueda elegir la opción que mejor se adapte a sus necesidades.

Usar su cuenta de RoCla VPN es así de sencillo

  1. Descargue su aplicación preferida

Elija una de las aplicaciones recomendadas en esta página para su sistema operativo. También puede utilizar cualquier otro cliente compatible con los protocolos de nuestro servicio.

2. Copie su clave de acceso o descargue su archivo de configuración

La clave de acceso que le proporcionamos permite configurar su cuenta de RoCla VPN. Si utiliza WireGuard, puede obtener un archivo de configuración (.conf) o un código QR para importar su cuenta directamente en la aplicación.

3. Importe su cuenta y conéctese

Abra la aplicación seleccionada e importe su cuenta mediante la opción correspondiente, que puede aparecer como «+», «Importar», «Añadir perfil» o «Pegar clave».

Si utiliza WireGuard, importe el archivo .conf o escanee el código QR que le proporcionamos.

Una vez configurada su cuenta, pulse «Conectar» para establecer la conexión VPN.

¡Listo! Ya puede disfrutar de una conexión rápida y segura con RoCla VPN. 👻✨

Programas recomendados

Hiddify

Recomendamos Hiddify como una de las opciones para gestionar sus cuentas de RoCla VPN, ya que es compatible con los protocolos Shadowsocks, VLESS/X-Ray, Hysteria2 y WireGuard.

Puede descargar la aplicación para su sistema operativo desde los siguientes enlaces:

⎋ Android | ⎋ iPhone | ⎋ Windows | ⎋ MacOS | ⎋ Linux

Ventajas y desventajas:

✅ Compatible con el protocolo Shadowsocks.

✅ Compatible con el protocolo VLESS/X-Ray.

✅ Compatible con el protocolo Hysteria2.

✅ Compatible con el protocolo WireGuard.

✅ Es un proyecto de código abierto.

✅ Está disponible para múltiples plataformas.

✅ Ofrece una interfaz fácil de utilizar.

✅ Está disponible en español.

✅ Permite activar la VPN desde el panel de ajustes rápidos o notificaciones.

✅ Admite túnel dividido: puede elegir qué aplicaciones pasan por la VPN.

❌ Su motor tiene un fallo conocido donde ignora el ajuste de «solo IPv4», por lo que en redes sin IPv6 algunas páginas pueden no abrir al usar Hysteria2.

❌ No siempre se reconecta solo tras un corte o un cambio de red.

❌ Las versiones 5.x pueden mostrar «No responde» aunque el servicio funcione bien; por eso recomendamos la versión 4.1.1 de Hiddify, que no presenta ese fallo.

Outline

Recomendamos Outline VPN Client para gestionar sus cuentas de RoCla VPN que utilizan el protocolo Shadowsocks.

Es una alternativa sencilla e intuitiva, especialmente para quienes buscan una aplicación centrada en este protocolo.

Puede descargar la aplicación para su sistema operativo desde los siguientes enlaces:

⎋ Android | ⎋ iPhone | ⎋ Windows | ⎋ MacOS | ⎋ Linux

Ventajas y desventajas:

✅ Compatible con el protocolo Shadowsocks.

✅ Es un proyecto de código abierto.

✅ Está disponible en español.

✅ Ofrece una interfaz intuitiva y fácil de utilizar.

✅ Está disponible para múltiples plataformas.

❌ No admite WireGuard ni otros protocolos distintos de Shadowsocks.

❌ No permite activar la VPN desde el panel de ajustes rápidos o notificaciones.

❌ No admite túnel dividido.

WireGuard

Recomendamos el cliente oficial de WireGuard para gestionar sus cuentas de RoCla VPN que utilizan este protocolo.

Esta aplicación permite importar la configuración de su cuenta y establecer una conexión mediante WireGuard de forma sencilla.

Puede descargarla para su sistema operativo desde los siguientes enlaces:

⎋ Android | ⎋ iPhone | ⎋ Windows | ⎋ MacOS | ⎋ Linux

Ventajas y desventajas:

✅ Compatible con el protocolo WireGuard.

✅ Es un proyecto de código abierto.

✅ Está disponible para múltiples plataformas.

✅ Ofrece una interfaz fácil de utilizar.

✅ Está disponible en español.

✅ Permite activar la VPN desde el panel de ajustes rápidos o notificaciones.

✅ Admite túnel dividido: en Android puede excluir aplicaciones del túnel.

❌ No admite otros protocolos distintos de WireGuard.
